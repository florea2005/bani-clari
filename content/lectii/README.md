# Lecții

Un fișier per lecție: `N-M-titlu-scurt.md` (N = nivelul, M = numărul lecției).
Fiecare lecție urmează șablonul din skill-ul `bani-clari` și are în antet: `status: ciorna | revizuita | publicata`, `revizor:` și `sursa:`.
Nicio lecție nu trece în `publicata` fără revizuirea unui specialist.
